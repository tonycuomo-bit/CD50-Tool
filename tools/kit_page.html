CD50 build kit

This page carries the CD50 plan set generator for the layout tool's Build PDF with Claude button. Each build starts a fresh Claude session with no copy of the repository, so the session reads kit/cd50-kit.b64.txt from here and builds the PDF from it.

The kit is a packed copy of cd50-plansets, rules, tools/new_site.py and sites from the CD50-Tool repository. Its first line names the commit it came from.

Refresh it after generator changes merge: python3 tools/build_kit.py, then republish this page with the new kit file.
